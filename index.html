FAIR WARNING

Client-side storage only

Kernel Quest saves your learning record only in this browser. There is no account, no server sync, and no recovery if this device loses the data.

  • Progress lives in local storage on this profile and origin.
  • Be fair in your tracking: export a JSON backup from Progress & backup before clearing site data, switching browsers, using private mode, or moving machines.
  • If you skip backups and the record disappears, that loss is yours.

Continuing means you accept local-only storage and personal responsibility for backups.
